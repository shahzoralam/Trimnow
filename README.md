# TrimNow – Barber Appointment Booking Platform

**An independently initiated and developed web application MVP**

TrimNow is a barber appointment booking platform designed to connect residents of gated residential communities with local barber shops. It enables customers to explore shops and services and book appointments, while providing barber and administrative management functionality.

## Live Application

https://trimnow.vercel.app/en

## Project Overview

TrimNow was independently initiated and developed from business concept and requirements definition through application architecture, database design, front-end and back-end implementation, testing and production deployment, using AI-assisted development tools.

The project demonstrates practical experience in software product development, technical project delivery and end-to-end application implementation.

## Key Features

- Customer-facing barber shop and service browsing.
- Appointment booking workflows.
- Barber access and management functionality.
- Barber working-hours and availability management.
- Time-slot blocking and scheduling controls.
- Super-admin access and administrative management.
- English and Arabic language support.
- Responsive web application interface.

## Technology Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Backend and Database:** Supabase
- **Development Tools:** Visual Studio Code, AI-assisted development tools
- **Version Control:** Git and GitHub
- **Deployment:** Vercel
